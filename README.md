# RincónLocal

Plataforma de reseñas de lugares de Montería, Córdoba, con rating por categorías (comida, servicio, ambiente) y ordenamiento por cercanía usando geolocalización del navegador.

## Requisitos
- PHP 8+
- MySQL/MariaDB
- Servidor local (XAMPP, Laragon, o `php -S localhost:8000`)

## Instalación
1. Importa `sql/esquema.sql` en tu MySQL (ya incluye lugares reales de Montería como datos de prueba).
2. Configura tus credenciales en `includes/db.php`.
3. Corre el servidor y abre `index.php`.
